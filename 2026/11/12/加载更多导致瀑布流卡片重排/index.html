照片瀑布流增加乱序问题

发表于 2026-11-12 | 分类于 tech
提示词列表明明只在数组末尾追加数据，旧卡片却跟着移动。记录一次 CSS 多列布局导致的分页重排，以及按批次追加的修复。

出现问题

最近在调整自己的 AI 提示词站。列表点“加载更多”后，新内容出来了，前面看过的卡片却也换了位置。刚才看到哪张，加载完还得重新找，浏览起来很不舒服。我想要的效果只是把新内容接在最下面，旧卡片留在原处。

排查问题

先检查接口和列表更新逻辑，发现数据已经是追加到数组末尾，也没有重新排序。卡片用的还是稳定的 ID，所以继续看外层布局。

问题出在 CSS 多列布局。原来所有卡片都放在同一个 columns 容器里，浏览器会尽量平衡各列高度。新增卡片以后，它会重新分配全部内容，旧卡片的位置也就跟着变了。

本地用原布局复现，从 24 张增加到 48 张，前面的 24 张里有 18 张发生了移动。数据顺序没变，视觉位置却变了。

解决问题

把列表改成按加载批次保存，每一批使用独立的多列容器。新的一批直接接在旧批次下方，已有容器里的卡片数量不变，就不会因为追加数据而重新分列，同时保留 ID 去重。
