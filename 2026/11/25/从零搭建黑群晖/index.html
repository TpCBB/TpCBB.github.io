从零搭建黑群晖：我家的 All-in-One NAS 是怎么跑起来的

发表于 2026-11-25 | 分类于 AI 与工具 |
一台 i3-12100 小主机，既备份电脑，也管家里的灯。记下装黑群晖时遇到的重启、镜像超时、共享文件夹消失，还有一块很难忽略的企业盘。

这台 NAS 还没装上系统，我就已经很熟悉它的开机画面了。引导 U 盘能认，菜单也能进，屏幕上刚跑过几行字就黑了。再一抬头，又是精粤的开机画面。

我原本只是想给 Mac 和 Windows 11 找个固定的备份地方，剪视频时能从局域网取素材，平时再放几个自己写的前端项目。既然打算让它一直开着，索性把 Home Assistant 也搬进来，管管家里的灯和开关。这就是我说的 All-in-One，没想到最先难住我的是开机。

我家这台怎么配的

  • CPU：Intel i3-12100。 备份文件用不到这么多性能，我留的余量主要是给 Docker 和虚拟机的。
  • 主板：精粤 B760i ITX。 我想把机箱做小一点，又不想在主板上花太多钱，最后选了它。
  • 硬盘：希捷 ST6000NM021A 企业盘。 买的时候看重可靠性，装进机箱才知道，噪音也该算进选购条件里。
  • 网络：光猫桥接，路由器拨号。 家里用有线 Mesh，NAS 接 2.5G 交换机。剪视频拉大文件时，我最能感觉到这笔钱花在哪儿。

出问题时，我会先看哪里

下面按症状分开写，点标题展开，再点一次就能收起。尤其是重启那一项，我没法把原因钉死在某个 BIOS 开关上，所以写的是排查顺序，不是一套必须照抄的设置。

还没看到 DSM 安装界面，机器就重启了

我先看一件事：黑屏之后，有没有重新出现主板的开机画面？如果有，确实是整机重启；如果只是屏幕不再输出，先去路由器看一眼设备列表。机器没起来，和机器起来了但找不到它，查的不是同一个地方。

  1. 从 BIOS 开始，一次只改一项。 先记下原设置。用 UEFI 引导时，我会先确认启动菜单里选的是 U 盘的 UEFI 启动项，再核对 CSM 和 Secure Boot。遇到引导被拦，可以试着关闭 Secure Boot；有的 BIOS 把相关选项放在 OS Type → Other OS。排查期间也可以暂时关掉 Fast Boot，方便看清自检过程。
  2. 换个 USB 口，再决定要不要换引导。 我会先试主板后置的 USB 2.0 口，排除前置接口的问题。如果仍然在同一位置重启，再拿备用 U 盘，用 Rufus 重新写入引导的 .img。写之前看清目标盘，别把数据盘选进去。
  3. 最后看引导配置和机型。 这套 i3-12100 + B760i 如果在原配置下始终过不去，SA6400 是一个可以试的机型，不代表选它就一定能好。如果机器已经不重启、只是局域网搜不到，再查网卡：确认板载网卡是不是 RTL8125，以及当前引导有没有带 r8125 模块。别为了一个网卡驱动，从头再调一遍 BIOS。
Container Manager 拉不下 Home Assistant 镜像

我这边报的是连接超时，容器都还没创建。一开始很容易顺手去改 Home Assistant 的配置，其实这时候它还没机会运行。

我最后用的是局域网里的 Clash / Mihomo，让 NAS 上负责拉镜像的 Docker 服务能通过代理访问镜像仓库，再回到 Container Manager 重试，镜像就拉下来了。这里容易弄混：电脑浏览器能走代理，不代表 NAS 也能；给将来的容器填代理，也管不到眼前这次拉取。没必要为了下载一个镜像，先把全家的网络都改掉。

File Station 里文件夹没了，空间却还占着

这比拉不下镜像吓人多了。我的第一反应是看剩余容量，发现空间并没有空出来。它不能证明文件都完好，但至少这时候别格式化，也别急着删了共享文件夹重建。

我会先打开「存储管理器」看卷是否正常，再去「控制面板 → 共享文件夹」找原来的名字。如果卷正常、共享也在，就对照当前账号和所属用户组的权限；如果是加密共享，再看它有没有挂载。熟悉 SSH 的话，可以只读查看对应卷上的原目录，确认几个熟悉的文件还在。查明确实是权限问题，再改那个共享的权限，不要给整卷递归放权。如果卷已经报错，就先停在这里，别把存储故障当成显示问题处理。

想在 File Station 看夸克网盘，迅雷套件又下不动

这两个问题我后来分开查。夸克的文件看不到，如果用的是 AList，就先看它能不能列出远端目录，再查 File Station 的 WebDAV 连接。迅雷能建任务但一直没速度，那是下载端的问题；就算网盘挂好了，也不会顺手把迅雷修好。

硬盘一忙起来，怎么跟炒豆子似的？

说的就是我这块希捷企业盘。读写时那阵声音，白天还能当背景音，放在安静的书房就很难不去听它。硬盘架加减震垫，可以少一点机箱跟着嗡嗡响的声音，盘本身的读写声还在。

如果重新安排位置，我会先把机器放到客厅靠近网线、通风也好的地方，再决定要不要买减震配件。卧室就算了，也别为了隔音把它塞进不通风的弱电箱。

现在用得最多的，反而都很普通

剪视频时，Mac 接上有线网络就能从 NAS 拉素材；换到 Windows 11，备份也有固定的去处。家里的绿米 D1 零火线开关和 S1E 智控屏接进 Home Assistant 之后，这台小机箱连灯也一起管了。

真要再装一台，我会把引导能正常启动时的 BIOS 设置拍下来。至于那块企业盘，不用拍照，我肯定记得把它放远点。
